Introducción al desarrollo web

El desarrollo web combina diferentes tecnologías para crear páginas y aplicaciones accesibles desde Internet.

HTML

HTML define la estructura y el contenido de una página web.

CSS

CSS controla la presentación visual y el diseño de la página.
